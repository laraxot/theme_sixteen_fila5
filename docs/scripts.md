# Scripts for Sixteen Theme

All JavaScript/Node utility scripts for the Sixteen theme are now kept in the **`scripts/`** sub‑folder. This keeps the theme root clean and makes the purpose of each file explicit.

## List of scripts

| Script | Description |
|---|---|
| `batch-parity.cjs` | Automated visual‑parity comparison using Playwright to check computed styles across pages. |
| `postcss.config.cjs` | PostCSS configuration for Tailwind, DaisyUI and custom plugins. |
| `take-screenshots-segnalazioni.cjs` | Capture screenshots for the “segnalazioni” wizard flow. |
| `take-screenshots-v2.cjs` | Second version of screenshot capture for regression testing. |
| `visual-compare-02-dati.cjs` | Compare visual data sets generated by Playwright. |
| `verify-stepper.cjs` | Verify the Filament stepper component behaviour. |
| `take-screenshots-phase2.cjs` | Screenshots for phase‑2 UI checks. |
| `take-screenshots-homepage.cjs` | Capture homepage screenshots for visual regression. |
| `map-picker-smoke.cjs` | Smoke test for the map‑picker component. |
| `inspect-fixcity-admin-ticket-create-map.cjs` | Debug script for the admin ticket creation map. |
| `quick-style-compare.cjs` | Quick style diff between builds. |
| `detailed-visual-compare.cjs` | Full‑featured visual comparison with diff images. |
| `dati-deep.cjs` | Deep data extraction for visual testing. |
| `check-header-local.cjs` | Verify that the header renders correctly in a local environment. |
| `check-all-pages.cjs` | Run a quick sanity check on every page of the theme. |

> **Note**: Scripts are executed via `node` or `npm run` commands as described in the project’s `package.json` scripts section.

For more details on each script’s usage, see the individual file headers or the **Visual Comparison** documentation under `docs/visual-comparison/`.
