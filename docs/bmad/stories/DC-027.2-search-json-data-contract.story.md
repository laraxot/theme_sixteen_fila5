# DC-027.2 — JSON data contract

## Story

As a content editor, I want filters, result cards, rating copy and contact
links in the page JSON, so that the Blade block contains no civic content.

## Acceptance Criteria

1. `tests.risultati-ricerca.json` contains stable `id` and `slug`, query,
   search labels, filter groups/items, result count, ten result cards,
   pagination and rating/contact data.
2. Italian visible copy is complete and no translation key is rendered raw.
3. Links are locale-aware route values or documented CMS URLs; no hardcoded
   reference-site paths are introduced.
4. The JSON validates as an object and remains compatible with the CMS block
   data merge contract.

## Tasks / Subtasks

- [ ] Add the reference filter taxonomy and counts (AC: #1).
- [ ] Add the ten reference result cards and load-more label (AC: #1, #2).
- [ ] Add rating questions/stars and contact actions (AC: #1, #2).
- [ ] Normalize URLs and validate the JSON contract (AC: #3, #4).

## Dev Notes

## Testing

- **Approach:** JSON parse/schema smoke plus rendered text assertions.
- **Key scenarios:** populated results; empty result count; missing optional
  description; Italian locale.
- **Fixtures / mocks:** `tests.risultati-ricerca.json`.
- **Edge cases:** empty filters, zero results and absent optional URLs.
