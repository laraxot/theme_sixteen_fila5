# DC-027.3 — Body markup and visual composition

## Story

As a citizen, I want search results presented with the same hierarchy and
rhythm as Design Comuni, so that filtering and scanning are effortless.

## Acceptance Criteria

1. The block renders breadcrumb, search form, two-column filter/results layout,
   result cards and load-more in the reference order.
2. It renders the rating and contacts regions before the shared footer.
3. Tailwind tokens reproduce reference colors, typography, spacing, borders,
   shadows and responsive breakpoints without Bootstrap CSS/JS/CDN.
4. At 375/768/1440 the layout has no horizontal overflow and preserves the
   reference mobile-to-desktop stacking behavior.

## Tasks / Subtasks

- [ ] Replace the two-card placeholder with the documented block composition
  (AC: #1).
- [ ] Add result-card, filter and pagination markup using reusable partials or
  a single documented block (AC: #1, #2).
- [ ] Add theme-owned Tailwind component styles and responsive rules (AC: #3,
  #4).
- [ ] Preserve the generic `tests/[slug].blade.php` entrypoint (AC: #1).

## Dev Notes

- Reusable markup belongs under `resources/views/components/blocks/`; do not
  create `pages/tests/risultati-ricerca.blade.php`. [Source: `laravel/Themes/Sixteen/docs/page-directory-structure.md#Tests`]
- Tailwind is the styling foundation; DaisyUI/Flowbite are restrained
  primitives. [Source: `bmad-output/front-office-design-comuni/architecture.md#ADR-003`]
- The body must remain server-rendered before enhancement. [Source: `bmad-output/front-office-design-comuni/architecture.md#ADR-004`]

## Testing

- **Approach:** Blade render smoke, DOM comparator, Playwright screenshots.
- **Key scenarios:** desktop filters; mobile stacked filters; ten cards;
  empty optional image/description.
- **Fixtures / mocks:** JSON story DC-027.2 and official reference URL.
- **Edge cases:** 320px width, long result title and zero results.
