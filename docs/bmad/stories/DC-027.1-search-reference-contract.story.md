# DC-027.1 — Reference evidence and block contract

## Story

As a theme maintainer, I want the official search-results page decomposed into
documented regions and data contracts, so that implementation is measurable
instead of based on visual guesses.

## Acceptance Criteria

1. The reference DOM is documented by region: shell, breadcrumb, search form,
   filter groups, results, pagination, rating, contacts and footer.
2. Each region lists its dynamic input fields and its owner (JSON, CMS block,
   section or layout).
3. The evidence records reference URL, local URL, viewport matrix and the
   baseline metrics 12.87% HTML / 24.02% visual at 1440.
4. The document explicitly forbids Bootstrap runtime dependencies.

## Tasks / Subtasks

- [ ] Extract and document the reference regions and hierarchy (AC: #1, #2).
- [ ] Record baseline screenshots and comparator commands (AC: #3).
- [ ] Record Design Comuni-to-Tailwind translation rules (AC: #4).

## Testing

- **Approach:** read-only DOM inventory and screenshot evidence.
- **Key scenarios:** desktop and mobile reference structure; no missing regions.
- **Fixtures / mocks:** downloaded reference HTML and screenshots.
- **Edge cases:** reference images and scripts must not be counted as body
  script parity tokens.
