# Story

Come sviluppatore Sixteen, voglio una view per ogni blocco homepage, così che il
markup sia riusabile e il JSON resti la fonte dell'ordine.

## Acceptance criteria

- [ ] Le tre sezioni reali sono mappate: hero con mappa/CTA, how-it-works,
  tracking rapido.
- [ ] I dettagli di autenticazione delle CTA (guest/auth) sono preservati.
- [ ] Ogni blocco ha una view in `components/blocks/` con dati espliciti.
- [ ] Nessun blocco contiene regole di dominio o accesso diretto alla persistenza.
- [ ] I nomi sono coerenti con il catalogo Sixteen e non introducono blocchi
  per features/statistiche/testimonianze non presenti nella fonte.

## Tasks

- [ ] Mappare sezioni hardcoded alle view esistenti prima di crearne di nuove.
- [ ] Riutilizzare blocchi esistenti e creare solo i minimi mancanti.
- [ ] Collegare ogni view al JSON tramite `data.view`.
