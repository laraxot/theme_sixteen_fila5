# Story

Come manutentore del tema, voglio una homepage Folio minimale come TwentyOne,
così che la composizione sia delegata al CMS.

## Acceptance criteria

- [ ] `pages/index.blade.php` conserva `name('home')` e monta il layout Sixteen.
- [ ] Il guscio usa il componente CMS con `side="content"` e `slug="home"`.
- [ ] La Blade non contiene heading, CTA, map, testo o sezioni homepage hardcoded.
- [ ] Non vengono introdotti Controller, Service layer o logica di dominio.

## Tasks

- [ ] Confrontare il shell Sixteen con TwentyOne (AC: 1–2).
- [ ] Spostare la composizione nei blocchi secondo story 1.3 (AC: 3).
- [ ] Verificare namespace layout e route name (AC: 1–4).

## Dev notes (locked)

Usare `Modules/Cms\View\Components\Page` come resolver; non implementare un
loader JSON nel tema. [Source: architecture.md#componenti-e-responsabilità]

## Testing plan (locked)

Test statico del file, render della route homepage per locale e verifica che i
blocchi provengano dal resolver CMS.
