# Come sostenere il progetto (studio Sixteen)

## Verdict

Ordine: B2G → partner istituzionali → grant → inbound (blog/eventi) → in-kind →
donazioni (con beneficiario) → sponsor commerciale eccezionale. **No** banner
commerciali permanenti nel footer al primo rilascio.
