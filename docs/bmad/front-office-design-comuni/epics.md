# Epic map

1. **Foundation and dependency removal** — tokens, shell, asset/runtime audit.
2. **Services and content discovery** — catalogue, category, detail, search.
   Search-results is sharded as `DC-027.1`–`DC-027.5` in the Sixteen theme
   backlog: evidence, JSON contract, body parity, WCAG interactions and gate.
3. **Segnalazione journey** — detail, four steps, confirmation and feedback.
4. **Reports and maps** — list, filters, map/list parity, detail and tracking.
5. **Identity and personal area** — auth, account, followed/recent reports.
6. **Quality and release** — accessibility, responsive, visual regression and docs.

Stories are intentionally small and own disjoint files. Existing stories in
`docs/stories/` remain project-level history; this workstream is the FO execution map.
