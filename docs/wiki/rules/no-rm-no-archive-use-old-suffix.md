# No rm, no archive folders, use .old suffix

Sixteen follows the same file retirement policy as modules.

Do not create `docs/archive/` or ad hoc archive folders for new work.

If an obsolete theme file must remain for traceability, rename it in place with `.old` and record the reason in `Themes/Sixteen/docs/wiki/`.
